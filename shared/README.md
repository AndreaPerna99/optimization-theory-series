# Shared Resources

Material used by more than one episode. Episode-specific material belongs in that episode's `assets/` folder instead.

| Folder | Holds | Versioned |
|---|---|---|
| [brand/](brand/) | logo, thumbnail templates, intro/outro elements | yes (source files) |
| [fonts/](fonts/) | the brand font files used by `gradkit/style.py` | yes, if the licence allows |
| [audio/](audio/) | music and stings (versioned if small); TTS voice models (not versioned) | partly |
| [footage/](footage/) | clips used by several episodes, e.g. the quadrotor in Episodes 0 and 9 | no |
