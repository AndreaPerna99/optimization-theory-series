# Audio

- **Music and stings:** versioned here if small, with their licence noted next to them.
- **Piper voices:** downloaded automatically by `./kg narrate` into `voices/` (not versioned).
- **Kokoro models:** put `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the kokoro-onnx releases into `kokoro/` (not versioned). Other file names can be set in `narration.toml` (`model`, `voices`).
